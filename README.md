# offshore-wind-sensitivity-Italy-Poland
Offshore wind energy develop avian sensitivity mapping for Italy and Poland following the method outlined below. This repository contains example code for each step, but is not fully reproducible as the data must be requested from the original sources. 

- More information on the seaward extension method and tracking data analysis can be found here: https://www.seabirdtracking.org/case-studies/conservation-toolkit/
- More information on sensitivity mapping can be found here: https://avistep.birdlife.org/

**Input Data Sources**
- Exclusive Economic Zone boundaries are available to at https://marineregions.org/downloads.php#unioneezcountry. 
- Species range maps and Important Bird and Biodiversity Area (IBA) polygons can be requested at https://datazone.birdlife.org/contact-us/request-our-data. 
- Tracking data are available for request at https://movebank.org (dataset 3028558214) or https://seabirdtracking.org (datasets 783–6, 788–9, 836–40, 869, 952–4, 1424–5, 1554–6, 1585, 1617–18, 1624, 1644, 1672, 1833, 1852–53, 1855, 1935–36, 1938–39, 1941, 2087–90, 2220–21, 2223–24, 2467). 
- Protected area polygons can be requested at https://protectedplanet.net.
- Other data were provide through collaboration with ISPRA and LIPU.

Output sensitivity map data are available at https://birdlife-hatch.org/topics/45895/page/data-request-italy.
